# Secure Virtual Lab Setup (Week 1, Task 1)

Part of the **Networkwalks Cyber Security Internship** (B084D, Batch 1).

## Objective
Build a virtualized lab where security tools can be practiced safely, with VMs that can talk to each other and the internet while the host machine stays protected.

## What I Did
1. **Installed VirtualBox:** set up the virtualization platform.
2. **Created a NAT network:** gave the VMs a shared, isolated network with internet access.
3. **Set up Kali Linux:** installed the OS and connected it to the NAT network.
4. **Saved a snapshot:** preserved a working configuration for quick restore.

## Takeaways
- Isolated labs keep security experiments contained and safe.
- NAT networking balances connectivity and protection.
- Snapshots make it easy to experiment and roll back.
